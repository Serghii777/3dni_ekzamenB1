# B1 editable landing

У цій версії дизайн зроблений HTML/CSS. Єдиним зображенням є фото Ірини (`assets/iryna.webp`).

## Що можна міняти в `index.html`
- дати;
- назву інтенсиву;
- заголовок;
- Telegram-посилання;
- декоративні написи біля фото;
- юридичні посилання і дані JDG.

## Що можна міняти в `styles.css`
- кольори;
- розміри тексту;
- розташування фото;
- розмір і швидкість пульсації кнопки;
- відступи та адаптивність.

Meta Pixel `1192959256037095` і подія `Lead` на натисканні Telegram-кнопки збережені.
