# 3 дні — екзамен B1

Готовий статичний сайт для Vercel.

## Запуск локально
Відкрийте `index.html` у браузері або запустіть:
`python3 -m http.server 8000`

## Публікація на Vercel
1. Розпакуйте архів.
2. Завантажте папку в GitHub або імпортуйте її прямо у Vercel.
3. Framework Preset: Other.
4. Build Command залиште порожнім.
5. Output Directory залиште порожнім.

## Таймер
Дата завершення задана у `script.js`:
`const TIMER_END = "2026-08-11T18:00:00+03:00";`
