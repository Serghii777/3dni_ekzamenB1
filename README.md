# Інтенсив B1 — 8–10 грудня

Це готовий статичний сайт для Vercel: `index.html` — головна сторінка, `reyestratsiya.html` — вибір пакета.

## Зміни
- Повернуто оригінальні заголовки, написи біля фото та кнопку з пульсацією (сердечко прибране).
- Додано нове фото, червоні кольори, білий фон і інформацію про спікерку.
- Таймер на 5 хвилин зберігає момент завершення в `localStorage` поточного браузера на обох сторінках. **Таймер не блокує реєстрацію чи оплату після нуля.**
- Meta Pixel 1192959256037095: PageView на обох сторінках; Lead на переході до Telegram з безкоштовного пакета; InitiateCheckout при натисканні на VIP після підключення оплати. Перехід у Telegram сам по собі не підтверджує завершену реєстрацію.

## Перед публікацією
1. У `script.js` вписати повний платіжний HTTPS URL у `VIP_PAYMENT_URL`. Поки його немає — кнопка показує повідомлення, платіж не здійснюється.
2. Перевірити, що Telegram-посилання на безкоштовний пакет актуальне.
3. Узгодити описи переваг обох пакетів і юридичні посилання.
4. Перевірити в браузері на мобільному пристрої, особливо кнопку й фото.

Завантажте в Vercel весь вміст цієї теки разом із `assets/iryna.png`.
